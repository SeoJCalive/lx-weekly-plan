# 작성 화면 기준

## 1. 용도
내부 PC에서 자기 처의 업무를 작성하고, 저장 전에 한글 양식에서 위치와 내용을 확인한다. 정의서 5.1–5.3, 5.12–5.14, 11장이 기준이다.

## 2. 색
종이 흰색, 짙은 먹색, 옅은 회색 바탕·가는 중성선을 쓴다. 주 동작은 먹색 면과 흰 글자다. 상태는 이름과 함께 회색(미작성), 파랑(작성 중), 보라(검토 요청), 적갈색(수정 요청), 초록(승인)으로 표시한다. 원본 문서의 색과 서체는 별도로 보존한다.

## 3. 활자
화면은 시스템 한글 고딕, 숫자는 고정폭 숫자. 크기는 12·14·16·20·26·36px, 굵기는 400·600·700. 미리보기는 명조 계열, 제목 12pt·본문 11pt·부가 설명 9pt.

## 4. 배치
간격은 4px 단위. 수평선 하나로 업무 맥락, 항목 선택, 필드, 문서 영역을 구분한다.

Layout: 접속 - 직접 입력과 계정 선택을 모두 노출 → split-screen (https://github.com/changeroa/StyleGallery/blob/main/patterns/split-sidebar/split-screen.md); scroll owner: document; anti-patterns: 좁을 때 필드를 압축하지 않는다.

Layout: 작성 - 입력 대상을 바꾸지 않고 결과를 확인 → supporting-pane (https://github.com/changeroa/StyleGallery/blob/main/patterns/split-sidebar/supporting-pane.md); scroll owner: document, 데스크톱 미리보기만 자체 스크롤; anti-patterns: 세로로 긴 문서 때문에 입력 영역이 밀려나거나 양식 열이 다시 배열되지 않는다.

## 5. 화면과 동작
- 접속: 주 동작은 접속. 이름·사번 → 최초 등록용 소속 처·직급 → 조직별 계정 목록. 목록 선택만으로 접속한다.
- 작성: 현재 처·주차 → 구분과 번호·상태 → 선택한 항목과 미리보기. 읽기 상태의 주 동작은 본인 할당, 편집 중 주 동작은 중간 저장이다.
- 필수: 다섯 메뉴, 역할·소속·이름, 계정 전환, 세 구분, 추가, 잠금·할당 해제, 제목·내용·부가 설명·표·담당자, 처 소제목, 저장 피드백, 주차 전체 다운로드.
- 제외: 미구현 메뉴 화면, 검토 버튼, 표·강조 편집 도구, 장식용 로고·타일·배지.

## 6. 구성 요소
브라우저 기본 button·input·select·textarea·table을 사용한다. 상태·버튼·입력은 공통 CSS, 원본 표는 별도 네임스페이스. 조직과 역할의 소속 관계는 API 응답을 따른다.

## 7. 표면
그림자·둥근 모서리·장식·애니메이션 없음. 주간 양식의 표 머리 음영만 원본에 맞춘다. 제품은 5.14의 흰 종이색 체계를 고정 사용한다.

## 8. 검증 대상
키보드 접근·포커스·명도 대비, 저장 전 이탈 확인, 잠금 소유권, 실시간 미리보기와 출력 보존, 좁은 화면의 표 가독성. 기준선은 UI가 없던 서버 안내 페이지이며, 사용감의 근거는 U2 인계서의 실제 화면 캡처에 둔다.
