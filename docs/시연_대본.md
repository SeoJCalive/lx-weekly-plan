# 주간업무 계획 시연 (핵심 다섯 장면 약 3분 30초)

## 준비

```text
bun run demo
bun run dev
http://127.0.0.1:4310
```

서버를 끈 상태에서 준비 명령을 실행한다. 아래 업무와 계정은 시연용이다. 계정을 바꿀 때는 오른쪽 위 **계정 전환**을 누른 뒤 **계정 선택**에서 이름과 사번을 확인한다.

핵심 시연은 1~5장면이다. 선택 장면은 약 1분 30초가 추가된다.

## 1. 요청을 받은 자리에서 수정 (50초)

- 계정: 안재형 / W2001.
- **첫 화면**의 **2027년도 예산편성 조정회의** 업무를 누른다.
- 붉은 테두리의 **수정 요청**과 문성일이 보낸 요청 카드가 보인다. 개최일을 넣어 달라는 짧은 요청이다.
- **내용** 끝에 ` / 11. 25.(수) 개최`를 붙인다. **수정 사유 (선택)**에 `협의된 조정회의 개최일을 추가했습니다.`를 입력하고 **저장 후 검토 요청**을 누른다.
- 상태가 **검토 요청**으로 바뀌고 수정 사유 카드가 보인다.

## 2. 처 검토와 취합본 상신 (35초)

- 계정: 문성일 / R0002.
- **첫 화면**의 해당 업무 **검토 →**를 누른다. 제출본과 작성자의 수정 사유를 확인한 뒤 **승인**을 누른다.
- 같은 화면의 **예산법무처 취합본 상신**을 누른다.
- 예산법무처 항목은 모두 승인이고 기획조정실 검토는 **검토 요청**이 된다.

## 3. 실·본부 승인과 배포 (45초)

- 계정: 서민철 / O0001. **첫 화면**의 **예산법무처 섹션**을 눌러 **승인**, 이어서 **기획조정실 취합본 상신**을 누른다.
- 계정: 윤재석 / D0001. **첫 화면**의 **기획처 섹션**을 눌러 **승인**한다. **첫 화면**으로 돌아와 **예산법무처 섹션**도 **승인**한다.
- AI혁신처·정보보안운영처·경영성과처의 최종 승인은 이미 끝나 있다. 기획처는 예산법무처와 함께 실 취합본에 올라온 것이다. 다섯 처가 모두 승인되면 **게시판에 배포**를 누르고 확인창에서 확인한다.
- 11.23.~11.27. **1차** 배포 완료 안내와 새 게시물이 보인다. 다음 주차도 자동으로 열린다.

## 4. 게시판에서 배포본 열람·다운로드 (30초)

- 계정: 윤재석 / D0001.
- **게시판**의 **배포본 목록**에서 `<11.23.~11.27.> 1차`를 선택한다.
- **표지 보기**를 펼쳐 표지를 확인하고, 다시 접어 다섯 처의 양식을 살펴본다. **HWPX 다운로드**를 누른다.
- 목록에는 지난 11.9.~11.13.의 1차·2차와 11.16.~11.20.의 1차도 남아 있다.
- 11.9.~11.13.의 **1차·2차**를 선택해, 재배포하면 이전 배포본을 보존하며 차수가 쌓이는 것을 보여준다. 선택 장면 없이도 버전 관리를 설명할 수 있다.

## 5. 지난 기록과 통계 (50초)

- 계정: 윤재석 / D0001.
- **기록**을 누르고 **작업 주차**를 `이전 주차 · 2026년 11. 16. ~ 11. 20.`로 고른다. **처**를 **예산법무처**로 고른다.
- **금주 계획**의 **연말 예산집행 전망 보완**을 누른다. 왼쪽 **수정 요청** 단계에서 보낸 사람·메시지를, 11.18. 10:00의 **검토 요청** 단계(오른쪽 제목 **검토 요청 · 2차**)에서 수정 사유와 달라진 내용을 확인한다.
- **처 전체**를 누르면 처 섹션의 상신·승인 단계가 나온다. 11.9.~11.13. 예산법무처의 처 전체에는 실 검토자의 항목 지목 수정 요청도 있다.
- **통계** 탭을 누른다. 처별 수정·수정 요청 횟수와 **준수 / 미준수**가 섞여 보인다. 11.9.~11.13. 주차로 바꾼 뒤 **통계**를 다시 눌러 지난주 수치도 확인한다.

## 6. (선택) 배포 뒤 보완하고 2차 남기기 (90초)

- 계정: 안재형 / W2001. **작성**에서 **작업 주차**를 `이전 주차 · 2026년 11. 23. ~ 11. 27.`로 고른다. **금주 계획**의 **2027년도 예산편성 조정회의**를 연다.
- **내용** 끝에 ` / 검토자료 사전 공유`를 붙이고 **수정 사유 (선택)**에 `회의 검토자료의 사전 공유를 보완했습니다.`를 적는다. **중간 저장**을 누르면 항목 승인이 풀려 **작성 중**이 된다. **검토 재요청**을 누른다.
- 계정: 문성일 / R0002. **작업 주차**를 같은 이전 주차로 고른 뒤 **첫 화면**의 해당 업무를 열어 **승인**, **예산법무처 취합본 상신**을 누른다.
- 계정: 서민철 / O0001. 같은 **작업 주차**를 고르고 **예산법무처 섹션**을 열어 **승인**, **기획조정실 취합본 상신**을 누른다.
- 계정: 윤재석 / D0001. 같은 **작업 주차**의 **예산법무처 섹션**을 열어 **승인**, **게시판에 배포** 후 확인한다.
- **게시판**에 11.23.~11.27. **1차와 2차가 함께** 보인다. 1차를 선택하면 보완 전 배포본이 그대로 남아 있다.

## 막혀야 하는 것 (실시간 시연 제외)

- 같은 처의 허윤정 / W2002: 안재형에게만 할당된 조정회의 항목을 수정하거나 검토 요청할 수 없어야 한다.
- 다른 처의 나현수 / W1001: 예산법무처 항목을 열어 수정하거나 검토 요청할 수 없어야 한다. 전체 주차 미리보기와 HWPX로 다른 처의 내용을 읽는 것은 가능하다.
- 다른 실의 강지훈 / O0002: 기획조정실 소속 예산법무처 섹션을 승인·수정 요청할 수 없어야 한다.
